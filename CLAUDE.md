# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

Quarkus 3.40 / Java 17 / Maven wrapper (`./mvnw`; `mvnw.cmd` on Windows).

- Dev mode (live reload, Dev UI at `http://localhost:8080/q/dev/`): `./mvnw compile quarkus:dev`
- Unit/`@QuarkusTest` tests: `./mvnw test`
- Single test class / method: `./mvnw test -Dtest=UserServiceTest` / `./mvnw test -Dtest=UserServiceTest#methodName`
- Integration tests (`*IT`, run against the packaged app): `./mvnw verify -DskipITs=false` — `skipITs` defaults to `true` in `pom.xml` and is only flipped by the `native` profile.
- Package: `./mvnw package` (output in `target/quarkus-app/`); native: `./mvnw package -Pnative`

There is no MySQL to install: the datasource uses Quarkus Dev Services (`mysql:8.0.35`, fixed port `33060` in `%dev`), so **Docker must be running** for dev mode and for tests. Schema is generated by Hibernate and seeded from `src/main/resources/import.sql` (an `Admin` and a `User` role plus one admin user `carroyom`).

No linter/formatter is wired into the build (the `checkstyle-maven-plugin.version` property in `pom.xml` is unused). Code follows google-java-format style (2-space indent, ~100 columns).

## Javadoc

All Javadoc is written in **Spanish** and must follow [docs/javadoc-style.md](docs/javadoc-style.md) (see also `AGENTS.md`) — read it before adding or changing any comment. Notable rules: third-person present-tense first sentence, `@throws` only for domain exceptions thrown by `UserService`/`AuthService`, REST methods guarded by `@RolesAllowed` end their first sentence with "Requiere rol {@code X}.", no `@author`/`@since`.

## Architecture

Single Quarkus REST service (`quarkus-rest` + Jackson, Hibernate ORM Panache, SmallRye JWT) under `com.carlosarroyoam.userservice`, organised by feature, with `core` for shared infrastructure:

- `auth/` — `AuthResource` → `AuthService` → `TokenService`. Login checks the account exists, is active, and the bcrypt hash matches, then issues an RS256 JWT (`upn` = username, `groups` = the user's single role title).
- `user/` — `UserResource` → `UserService` → `UserRepository` / `RoleRepository` (Panache repositories), with `entity/` (`User`, `Role`) and `dto/`.
- `core/` — `ClockConfig` (produces the injectable `Clock`), `AppMessages`, `ExceptionMapper`, `AppConstants`.

Cross-cutting conventions that span several files:

- **Layering**: resources do HTTP only (return `RestResponse<…>`); services hold business rules, own `@Transactional`, and return DTOs — entities never leave the service layer. Dependencies are constructor-injected.
- **DTO mapping**: each DTO that needs mapping nests a MapStruct `@Mapper` interface with a static `INSTANCE` (e.g. `UserDto.UserDtoMapper`); services call `UserDtoMapper.INSTANCE.*`. Lombok + MapStruct run as annotation processors (see `lombok-mapstruct-binding` in `pom.xml`).
- **Time**: services must use the injected `Clock` (`LocalDateTime.now(clock)`) rather than the system clock so tests can substitute it. `createdAt`/`updatedAt` are set manually in services, not by JPA.
- **Error messages (two-tier)**: `AppMessages` is a Qute `@MessageBundle` backed by `src/main/resources/messages/msg.properties`. Each failure has a generic message (returned to the client in the exception) and a `…Detailed` variant (contains username/email/id; only written to the log). Adding a message means adding both the interface method and the `msg.properties` key.
- **Error responses**: `ExceptionMapper` (`@ServerExceptionMapper`) converts `WebApplicationException`, `ConstraintViolationException` and any other `Exception` to `AppExceptionDto` JSON. Services signal domain errors with `BadRequestException`/`NotFoundException` (user) and `AuthenticationFailedException` (auth); unexpected errors become a generic 500.
- **Security**: `UserResource` is class-level `@Authenticated`; most methods add `@RolesAllowed("Admin")`. `self` and `change-password` act on the *authenticated principal* (looked up via `SecurityContext`), not on the `{userId}` path segment. Delete is a soft delete (`isActive=false`); new users are created inactive.
- **JSON**: Jackson uses `SNAKE_CASE` (`quarkus.jackson.property-naming-strategy`), so API field names differ from DTO field names.
- **JWT keys**: `privateKey.pem` / `publicKey.pem` live in `src/main/resources` and are explicitly included in native builds via `quarkus.native.resources.includes`.
- Health checks are served under `/api/v1/health`; REST endpoints under `/api/v1/…`; OpenAPI via `quarkus-smallrye-openapi`.

## Testing

Tests are `@QuarkusTest` classes under `src/test/java` mirroring the main packages: `*ServiceTest` (service logic with `@InjectMock` repositories), `*ResourceTest` (HTTP via RestAssured, `quarkus-test-security`), and `*ResourceIT` classes that simply `extend` the matching `*ResourceTest` annotated with `@QuarkusIntegrationTest` to re-run the same tests against the built artifact.
